# Menu portrait

`menu-portrait-lavender.png` is the approved menu character direction, generated
from this project's existing `scenes/home.png` portrait as a circular avatar on
2026-10-26. It is a static UI image, not a new Live2D model or animation.

The context menu uses this high-resolution RGBA source and resamples it at the
current display scale. The older `menu-avatar*.png` files remain available to
other legacy consumers; they are not a fallback for the new menu portrait.
