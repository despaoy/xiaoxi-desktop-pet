# 小汐小屋场景插画

本目录是为已确认的小屋视觉方案生成的静态界面插画，不是 Live2D 动作文件或模型绑定。切换页面可以切换插画；不应声称桌面模型已经能完成插画中的姿势。

- `home.png`：窗边双手托腮，温暖的欢迎状态。
- `focus.png`：安静伏在书本上，适合专注、时间回顾和设置。
- `interaction.png`：轻轻举手打招呼，适合互动与快捷工具。

三个 PNG 均为 1254 × 1254。图像左侧为角色与窗边场景，右侧淡入暖奶油色背景。不要拉伸人物，也不要把全幅压成很扁的条幅导致脸被裁掉。界面文字、气泡、按钮和状态应由真实控件绘制；本图没有烘焙这些元素。

## 来源与生成方式

2026-10-24 使用内置 imagegen 生成，以本项目已确认的六页设计图作为角色与画风参考；后两张同时参考 `home.png` 以统一形象。没有使用第三方项目的角色图片。原 `menu-avatar.png` 和 `app-icon.png` 未修改。

## 提示词要点

共同约束：同一白紫长发、淡紫卷龙角、尖耳朵、紫眼睛、花形发饰及白紫连衣裙的小汐；柔和日光、奶油色与淡紫窗边，适量书本和植物；半身角色位于画面中左，龙角和手完整保留；方形构图，最右侧约 20% 柔和融入 `#fffaf3`；细腻动漫线稿。禁止任何文字、数字、按钮、图标、气泡、计时器、商标、水印、应用边框或黑色底边。

- 首页提示：双手轻托下巴，平静欢迎的微笑，人物脸部清楚、占比适合界面主视觉。
- 专注提示：两臂和下巴轻放在两本淡紫书籍上，安静、轻柔、专注的陪伴神情；不疲惫、不悲伤、不睡着。
- 互动提示：一只手肘放在窗台上，另一只手在肩旁做小幅张掌招呼，自然五指、轻快微笑；避免夸张伸手透视。
