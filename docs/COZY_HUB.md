# 窗边小屋：界面接入与验收边界

## 真实功能与兼容入口

六个页面使用真实控件、快照和命令，不将 AI 效果图当成可点击页面，也不把示例数据写入用户数据库。

- 首页：真实计时、下一次提醒、最多四项常用动作、本地一句话指令和通知记录。
- 专注与事项：自定时长、开始/暂停/继续/结束/休息，待办完成与恢复，单次或重复提醒及稍后提醒。
- 动作互动：从动作注册表读取全部当前可用动作；自动行为、短句、台词编辑、角色显示与大小。执行能力仍受当前渲染器和模型限制。
- 快捷工具：入口与场景管理、收藏、打开/编辑/删除，音量增减、静音和锁屏；场景只打开保存的入口，不增加任意脚本能力。
- 时间回顾：今天/近 7 天/近 30 天、应用和分类统计、限时、统计暂停和连续使用提醒。计划专注分钟数不代表实际注意力。
- 设置：免打扰、通知、启动、双击动作、收藏快捷键、插件开关及本地数据入口。停用插件和部分快捷键设置仍需重启。

非 Live2D 模式的 PNG 外观导入/恢复、配色、插件说明与权限详情等保留旧编辑器入口。新界面异常或缺少 Qt 时回到旧 Tk 小屋，不能把回退描述为所有页面已全面迁移。

## 插画与动作

`assets/ui/scenes` 中三张图分别用于欢迎、安静陪伴和互动场景。它们是新生成的静态插画，不是 Live2D 模型新动作；桌面角色依然使用现有动作管线。界面短句应根据页面和状态变化，不以催促、责备或未经实现的记忆/健康承诺替代真实功能。

## 数据与进程

数据库格式和数据目录保持兼容；Qt 不另开数据库，不加载插件，只发经过验证的意图。原 Tk 宿主是唯一数据写入者。详情见 `QT_HUB_PROTOCOL.md`。所有 OS 操作测试应使用模拟，不在测试中真的锁屏、更改开机启动或启动外部文件。

Qt 子进程不计入使用统计；编辑新界面输入框时通知主进程减少自动闲聊；角色隐藏且热键不可用时，关闭小屋仍须恢复角色作为入口。

## 验收限制

Linux 离屏渲染、纯逻辑回归和独立进程启动测试不能替代 Windows 真机验收。交付时分别列出已通过的测试和未运行的 Windows DPI、字体、多显示器、托盘/热键及实际安装包验证。源码包不含个人数据，也不含完整外部分发的 Live2D 模型运行时。
